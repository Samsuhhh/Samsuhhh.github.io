01About

I'm a front-end developer in San Jose. At Honest Digital, I've been building and maintaining 30+ client web properties across AEM, WordPress, DealerInspire, DealerOn, and Dealer.com. A lot of it is compliance-critical work, including FTC disclosure builds, PII handling, and WCAG accessibility compliance.

I care about the parts of front-end that don't demo well: accessible markup, cross-browser behavior, and components other people on the team can actually reuse. Lately, I've been building my own tools and assistants, and that's how CareerOS and SamOS were born.

03Projects and Tools

CareerOS Since 2025 · private

A job application tracker that outgrew being a tracker. Started as a localStorage kanban board, now runs on Cloudflare Workers with a D1 database, serving a REST API for applications, materials, and activity logging. Includes an LLM-backed tailoring pipeline that runs a two-stage pass over a job description: a skeptical hire-likelihood assessment first, then materials tailored against that assessment.

Cloudflare Workers · D1 · Vanilla JS · Anthropic API

Private repo. Architecture detail on request.

SamOS Since 2025 · private

The system CareerOS was carved out of. A personal operations layer on Claude Code and MCP: an achievement library that keeps every claim traceable, skills for company research and resume tailoring, and agents that draft but never send.
